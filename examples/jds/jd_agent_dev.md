# Agent 应用开发工程师（实习 / 校招）

岗位职责：

1. 基于主流 Agent 框架开发能解决实际问题的智能体应用。
2. 把业务系统的 API 封装成工具，供 Agent 调用并做参数校验。
3. 搭建 RAG 检索增强链路，关注召回质量与幻觉率。
4. 为 Agent 设计评测集与回归测试，持续压低失败率。

任职要求：

1. 熟悉 Python，能写可维护的后端代码并部署上线。
2. 深入理解 Agent / 多智能体编排，有 LangChain / Dify / Coze 实战。
3. 掌握函数调用 / 工具调用的完整链路（含失败重试与校验）。
4. 有 RAG 实践经验，能报出 Recall@k 与幻觉率等量化指标。
5. 习惯用 Claude Code / Cursor 等 AI 编程工具提升交付效率。

优先条件：

1. 在开源社区发布过 Agent 相关项目。
2. 具备工程落地与部署经验（Docker / 数据库 / 服务）。
