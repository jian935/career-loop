# AI 产品经理（校招 / 培养计划）

岗位描述：

负责 AI 产品的需求洞察与方案设计，把大模型能力翻译成用户真正用得上的功能。
你将参与从用户访谈、需求定义到上线复盘的全流程。

岗位职责：

1. 深入业务场景，通过用户访谈和数据分析挖掘真实需求。
2. 设计 AI 功能的交互逻辑与评测标准，定义产品成功指标。
3. 推动研发、算法、设计协同落地，跟踪上线后的效果数据。
4. 建立产品的效果评估体系，用数据验证每个迭代是否真的变好。

任职要求：

1. 对大模型的原理与能力边界有清晰认知，能判断什么该用 AI 做什么不该。
2. 熟练使用提示词工程，能独立把模型调到一个可用的状态。
3. 具备数据分析能力，能搭建基础看板、定义漏斗与转化率指标。
4. 良好的跨团队沟通协作能力，能把技术语言翻译成业务语言。
5. 有 Agent / 工作流 相关的实践或强烈兴趣。

优先条件：

1. 自己动手做过 RAG 或 Agent 类小项目，并公开过复盘。
2. 熟悉至少一个 Agent 框架（如 Dify、Coze、LangChain）。
