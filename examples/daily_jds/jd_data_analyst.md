# 数据分析师（商业分析方向）


岗位职责：

1. 负责业务指标体系搭建与日常监控，产出可复用的分析看板。
2. 针对增长与留存问题做专项分析，给出可落地的策略建议。
3. 与业务方对齐口径，把分析结论推进到执行层。

任职要求：

1. 熟练使用 SQL 取数，能用 Python 做数据清洗与统计。
2. 掌握指标体系与 AB 实验方法论，能独立完成归因分析。
3. 有数据可视化经验（Tableau / Superset / 帆软等任意一种）。
4. 具备良好的业务理解与表达沟通能力。

优先条件：

1. 有电商或内容行业的数据分析经验。
2. 做过用户分层与生命周期价值分析。

本岗位长期有效、招满为止，建议尽早投递。
